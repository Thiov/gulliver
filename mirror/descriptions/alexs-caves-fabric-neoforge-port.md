# Alex's Caves (Fabric/NeoForge Port)

An unofficial port of **Alex's Caves** to Fabric and NeoForge for Minecraft 26.1.2.

Alex's Caves adds rare, hand-crafted cave biomes deep beneath the Overworld, each with its own blocks, creatures, items and secrets. They are hard to find and worth the search.

## Requirements

- Minecraft **26.1.2**, Java 25
- **Fabric** (with Fabric API) or **NeoForge**
- **Citadel** for 26.1.2, installed separately (the same Citadel Alex's Mobs uses, so both mods work together)
- JEI is supported but optional
